fix: the /loopSEC report is in Chinese, and so is the coverage headline

The sec report's scaffolding was English while every finding's body was already
Chinese, so the document switched language in the middle. It now follows
`settings.reportLanguage` — zh by default, en available — exactly as the hypothesis
report does.

All of it lives in `reportText.ts` as a SECOND TABLE (`SecStrings`) beside
`ReportStrings`, not in a second file. The rule that file exists to enforce is "one
object per language so a new string cannot be added without both being updated", and
splitting the sec strings out would leave that rule in two places.

THE COVERAGE HEADLINE MOVED TOO, and it was the same bug in the OTHER report. It is
printed INSIDE the report, so a Chinese report said:

    | **被假设引用过的文件** | 1 of 32 file(s) cited (3%) |

— an English sentence in the middle of a Chinese document, which reads as a bug.
`coverageHeadline(report, lang)` takes the language now and both reports pass theirs.
It had to take PRIMITIVES rather than a `CoverageReport`, because coverage.ts imports
reportText.ts and the reverse would be a cycle; the formatting lives in
reportText.ts so both languages stay in one place.

TWO SMALLER LEAKS, found by rendering the report and reading it rather than by
grepping for strings: `(still running)` in the run header, and `**no**` in the
"recon note recorded" row. Both are translated now.

WHAT IS NOT TRANSLATED: the finding titles, the reasoning and the evidence. Those are
the model's words, recorded verbatim, and paraphrasing them would be the report
laundering its own evidence — the thing this project exists to avoid. A Chinese
report therefore needs a brief that tells the model to write in Chinese, and
`reportLanguage` already drives both.

`reportLanguageOf` moved from loop.ts to settings.ts. loop.ts imports sec.ts, so
sec.ts could not import it back; it is re-exported from loop.ts because index.ts and
the tests import it from there.

VERIFICATION

The sec tests were asserting English strings, so they were rewritten to pin BOTH
languages — a test that only checked one would have passed on a report that ignored
the setting. The coverage test gained the English half for the same reason.

793 tests, 0 failures, tsc clean.
