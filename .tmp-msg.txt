THE DUPLICATE TESTS — 13, and they were not all the same kind of duplicate

  10  byte-identical       a block in command.test.ts (696-880) copy-pasted to 881-1060
   1  byte-identical       loop.test.ts 1529 copied to 1619
   2  same test MINUS COMMENTS   the copies had their explanatory comments stripped

That last pair is why the byte-identical check was not enough: the first version of the
script refused them ("body is NOT identical — refusing to delete"), and only comparing
comment-stripped bodies showed they were the same test. The comment-carrying version is
the one kept.

The script verifies before it deletes: it locates each block by the next `^\}\);$`, checks
the target really is a duplicate of an EARLIER test, and throws rather than guessing if a
body does not match. It also found its own bug the honest way — one run deleted 10 tests
from command.test.ts and then failed on loop.test.ts because the block detector's line
numbers had already shifted, so the rm in the `&&` chain never ran and a .tmp file was
left behind.

841 → 828 tests. Nothing was lost: the count went down by exactly the number deleted.
