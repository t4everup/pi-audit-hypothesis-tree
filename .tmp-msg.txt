THE ORDER IS THE FIX. What it is → where and whether it needs auth → HOW TO RUN IT → the
chain → the evidence. A hunter wants to paste the PoC, so it comes before the reading.

THE CHAIN IS NOW A FIELD. `SecFinding.path` — a structured list of steps, rendered as a
fenced NUMBERED list with each `file:line` on its own line above its detail, so the
location column reads down the page. The model was ALREADY producing this chain; it was
just writing it as prose. When there is no structured path the prose is fenced as the
chain instead, which at least stops the renderer mangling the `#` and `【】` inside it —
the 30 `#`-leading lines in the real report were shell comments in PoCs and were correctly
inside fences, so that was NOT the bug it first looked like.

CUT: four labelled lines became one strip; the wall-clock ISO timestamp went (the round
number is what a reader traces back with); the two-line per-finding disclaimer became one
line, because the full table is in the preamble where a reader meets it BEFORE the
findings rather than after each of them.
