feat: the report says the REPRODUCED tier was unreachable, and why

REPRODUCED needs a command probe, and `allowCommandProbes` is off by default. So
on any default project NOTHING can reach the top tier — measured on the real
Centreon audit, 13 of 13 confirmed findings were STATIC and none was reproduced.

The report never said so. A reader seeing "STATIC" on every finding concludes the
tool is weak, when it is a disabled setting — and the setting is a deliberate
consent gate, so it is the operator's to open.

  - **「已复现」这一档本次一条都没有。**它需要 command 探针，而 `allowCommandProbes`
    默认是关的，所以 0/13 条确认发现全是「静态」——**这是设置的后果，不是审计的
    结论**。打开它（`/hypothesis config allowCommandProbes=true`）重跑，才能把静态
    论证变成可重跑的复现。

- `RenderReportOptions.allowCommandProbes`, and `writeReport` reads the setting
  itself so a caller cannot forget to pass it. `renderReport` stays a pure
  function of the snapshot — the read happens in the I/O layer.
- Rendered only when the gate is actually OFF: a report where REPRODUCED is
  reachable must not carry a caveat about it.

4 new tests, including one that flips the setting and asserts the caveat
disappears from the written file.
